# 📖 聽書學英文

用英文經典學英文的網頁 App（PWA）：**每一段先唸英文、再唸中文翻譯**。
書都是 Project Gutenberg 的公有領域作品，可以合法免費閱讀；翻譯用瀏覽器內建的離線翻譯，免費、不用帳號。

## 功能

- **熱門經典**：依 Gutenberg 全球下載量排序（傲慢與偏見、福爾摩斯、愛麗絲、科學怪人…），也可以用書名或作者搜尋，約 6 萬本英文書
- **中文書名**：約 170 本常見經典內建台灣常用譯名（例如 *The Great Gatsby* →《大亨小傳》），也能直接用中文書名或作者搜尋（「福爾摩斯」「狄更斯」）；
  其他書用內建翻譯自動翻書名，標示「機翻」
- **雙語朗讀**：順序可選「英→中」「英→中→英」「英→英→中」「只有英文」；英文、中文速度分開調
- **畫面**：英文和中文對照顯示，正在唸的那一種語言會亮起來；可以隱藏中文練聽力
- **記住進度**：關掉再打開會接著讀；超過 10 分鐘沒聽，會自動倒退一段
- **收藏句子**：收藏時連同中文翻譯一起存，可以加備註（例如生字）
- **睡眠定時**：5～90 分鐘或「本章結束」，最後 30 秒音量漸弱
- **匯出／匯入**：在電腦翻譯好整本書，匯出成 .json 檔帶到手機用

## 啟動

雙擊 `start.bat`，會用 Edge 打開 http://localhost:8001
（或手動執行 `python -m http.server 8001`，必須透過網址開啟，直接雙擊 `index.html` 不能用）

## 翻譯怎麼運作

- 使用 **Microsoft Edge（或 Chrome）電腦版內建的離線翻譯**。第一次按 ▶ 播放時會下載翻譯模型（只需要一次，約十幾秒）。
- 播放時會邊聽邊翻譯後面幾段；每段只翻一次，翻好就存起來，之後不用網路。
- 想一次翻完：在播放頁按「翻譯整本」。一本小說約 1,000～5,000 段，大約 5～20 分鐘。
- 翻譯品質大約是一般機器翻譯的水準，意思通常正確，但文學性的句子偶爾會生硬。

## 在手機上用

網址：**https://stevenhuang0715.github.io/listen-english/**
（用手機瀏覽器打開後選「加入主畫面」，就能像 App 一樣使用）

手機瀏覽器目前多半沒有內建翻譯，所以流程是：

1. 在電腦的 Edge 加入書本，按「翻譯整本」。
2. 按「匯出（帶到手機）」，得到一個 .json 檔。
3. 把檔案傳到手機（LINE 傳給自己、Email、雲端硬碟都可以）。
4. 手機打開上面的網址 →「加入書本」→「匯入檔案」選那個 .json。

更新網站：改完程式後執行 `git add -A`、`git commit`、`git push`，GitHub 約 1 分鐘後會自動更新。

## 版權

- 書目和全文來自 [Project Gutenberg](https://www.gutenberg.org)（全文經由 Internet Archive 下載），都是美國的公有領域作品。
  熱門書單裡的作者幾乎都已過世超過 50 年，在台灣也屬公有領域（著作權法第 30 條）；少數 20 世紀作品請自行確認。
- 「匯入檔案」請只匯入公有領域或你有權使用的文字。
- 少數較新的 Gutenberg 書在 Internet Archive 沒有副本，這時會顯示「手動下載」：
  到 Gutenberg 頁面下載「Plain Text UTF-8」，再用「匯入檔案」加入。

## 注意事項

- 資料存在瀏覽器裡（IndexedDB），清除瀏覽器資料會一起刪除；電腦和手機的資料不會自動同步（用匯出／匯入搬）。
- 語音朗讀用的是系統語音。**Edge 的「Online (Natural)」語音最自然**，可以在播放頁的「聲音設定」選。
- 部分手機在螢幕關閉後會暫停語音朗讀，這是瀏覽器的限制，建議螢幕保持開啟並調到最暗。
- 熱門排行用的 Gutendex 是志工維護的服務，連不上時會改顯示內建的經典書單。

## 檔案結構

```
index.html            畫面
css/style.css         樣式（夜間配色）
js/app.js             主程式：書架、播放畫面、加入書本、收藏、睡眠定時、匯出匯入
js/player.js          雙語朗讀播放器（英文→中文的播放順序）
js/translate.js       內建離線翻譯 + 翻譯結果快取
js/catalog.js         書目：Gutendex 熱門排行、Internet Archive 搜尋與全文下載
js/zhtitles.js        中文書名：經典譯名對照表、中文搜尋、機器翻譯書名
js/textbook.js        英文書解析：去掉 Gutenberg 前言、分章、切成朗讀片段
js/db.js              IndexedDB：書本、原文、翻譯、進度、收藏
sw.js                 Service Worker（可安裝成 App、離線開啟）
manifest.webmanifest  App 資訊
icons/                圖示
start.bat             Windows 一鍵啟動
```
